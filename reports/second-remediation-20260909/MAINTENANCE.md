# Maintenance boundaries

- **Search:** query `q`, repeated `f.<supported-filter>` and `limit` share the same restore path. Typing uses one debounced history entry; filter and pagination changes push boundaries. Preserve unrelated parameters. Test input before/during loader initialization, Back/Forward, an exact ID and an exact quoted empty term. Do not patch rendered excerpts; retain separators in structural source HTML during indexing. Keep the search page's no-referrer policy through release normalization and keep automatic analytics off that page.
- **References:** enrich through `reference-metadata-lib.mjs` and documented `data/reference-metadata-overrides.json`. Keep IDs and identifying query parameters; retain anchor/publisher provenance. Host identity is not authorship or independent evidence. Exact known publisher/hosting-domain aliases share a filter label; unrelated organizations and documents remain separate. Publication metadata recovery is not claim verification. Review endpoint roles before any retrieval; indicators and reserved examples remain inert. Rebuild full model, compact projection, static pages and structured graph together. Stable `#reference-<record-id>` anchors remain supported, as do raw exported record-ID fragments.
- **Directory semantics:** direct search includes descriptive record fields/tags. Relationship-only matches belong in Find related; they are not counted as direct YARA hits. Display the complete preserved-record count separately from bibliographic/tool/dataset count. Preserve full exports and ordinary static links; no giant initial DOM.
- **ATT&CK:** pin release/domain and retain input content hash plus the exact serialization method. A versioned filename on `master` is mutable. Rebuild core summaries and defense buckets together; verify DET0202/AN0578, citation labels, empty relationships, missing import and failed load. ATLAS is not Enterprise ATT&CK. Never interpret relationship counts as coverage.
- **Actor research:** the overall page remains unverified while the appendix has unresolved claims. Update the claim/recovery register when reviewing a fragment; an identifier validator does not perform semantic review. Follow the existing editorial policy. Do not guess old citation-number mappings or promote vendor overlaps to universal aliases.
- **Canonicals:** use `trailingSlash: true` in both Docusaurus sources and keep CTI authored SEO route keys consistent. Test raw initial HTML, not only hydrated DOM, across all generator siblings. Keep build formatting separate from editorial-review dates.
- **Accessibility:** `.engagement-map` and `.lab-group` own their theme tokens, including nested practice panels. Keep guide-card wrapping scoped; retain independently scrollable tables/code. Contrast measurements must decode both `rgb()` and `color(srgb …)` and composite alpha over the actual background. Inspect representative screenshots and keyboard paths; automated passes are not certification.
- **Budgets:** References first decoded HTML <=200,000 bytes; Knowledge Sources <=250,000; directory DOM <=3,200 nodes. Record cold and first-interaction measurements under the same cache, compression, network and CPU profile. New metadata is a justified payload increase only within the guard and with working retrieval.
- **Examples:** preserve versioned authored fixture bytes, expected JSON, negative controls and explicit simulation/static-analysis boundaries. Run all three Python examples when changing validators or downloads. The ZIP is a benign deterministic training artifact, not a scanner input recommendation.
