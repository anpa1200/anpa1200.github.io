PowerShell 4104 — Script block logging

PowerShell 4104 — Script block logging. PowerShell logs script-block text with an identifier and multipart sequence fields.

powershell xml script execution

Source and collection

Windows PowerShell: Microsoft-Windows-PowerShell/Operational. PowerShell 7 uses PowerShellCore/Operational after registration.

Enable the corresponding module or script-block logging policy for the target edition. Read with Get-WinEvent; protect potentially sensitive script content.

Validation boundaries

Logging and automatic suspicious-script behavior differ by version; script text is not proof every command completed.

This sample passed byte-integrity and JSON/XML parsing checks, including the catalogue’s specified event discriminators. This is not a complete vendor-schema validation or a tested detection.

For a simulation, first parse this fixture offline, then create a separately labelled synthetic variant and test it against the intended collector in an isolated lab. Never replay public example identities or destinations into production.
