Suricata EVE pgsql. EVE JSON emits typed records from the Suricata network engine.

Source and collection

Configured eve-log output, commonly eve.json.

Record Suricata version, enabled EVE types, ruleset and IDS versus inline IPS mode.

Investigation uses

  • Correlate flow_id and event_type with related protocol and alert records.
  • For alerts, review signature, action and packet context before assigning a verdict.

Validation boundaries

An alert is a rule match, not independently confirmed compromise. Fields and nested structures differ by event type and version.

This sample passed byte-integrity and JSON/XML parsing checks, including the catalogue’s specified event discriminators. This is not a complete vendor-schema validation or a tested detection.

For a simulation, first parse this fixture offline, then create a separately labelled synthetic variant and test it against the intended collector in an isolated lab. Never replay public example identities or destinations into production.
