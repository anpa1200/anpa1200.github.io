Security log-source library

Security log-source library. 82 documented log profiles grouped by system, with native examples, field structure, collection guidance and investigation uses.

A curated, expandable catalogue of concrete producer formats. It is not an exhaustive inventory of every product, event ID or release. Reviewed 2026-11-10.

What “real example” means here

Examples are preserved publisher documentation or pinned upstream parser fixtures, with provenance and any extraction or repair disclosed. They are not independently captured incidents. Offline syntax checks do not certify a vendor schema, collector or detector.

Use a sample for research

  1. Select the exact producer, event type and serialization.
  2. Read the provenance and version limits before downloading.
  3. Verify the SHA-256 hash and parse the sample offline.
  4. Keep raw values and normalized fields separate; record any transformation.
  5. Test a collector only in an isolated, approved lab with explicit positive and negative controls.

Do not execute commands, URLs or scripts contained in log records. These are data.

Coverage and expansion

This edition covers Windows, Linux, macOS, endpoint alerts, network/perimeter, cloud, identity/SaaS, web/database and container sources. It does not yet enumerate every event ID, OT/ICS product, mobile platform, email gateway, storage appliance or vendor release. A new profile requires a cited native example, version boundary, structural checks and collection semantics.
