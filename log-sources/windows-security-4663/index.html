Windows Security 4663 — Object access

Windows Security 4663 — Object access. An audited object access was recorded for the configured object and access mask.

windows xml file object-access

Source and collection

Windows Event Log: Security; archived .evtx is binary, while this fixture is an XML event export.

Configure Audit File System or applicable object subcategory plus SACL. Read with Get-WinEvent and preserve provider, event ID, version, computer and record ID.

Native example and provenance

publisher documentation example. Published example; no independent capture provenance claimed.

Investigation uses

  • Inspect access to sensitive objects and correlate process ID, logon ID and object name.
  • Compare event time with ingestion time and retain the original XML for a reviewable evidence trail.

Validation boundaries

Audit policy alone is insufficient without an applicable SACL; access does not establish exfiltration. This sample uses event version 1.

This sample passed byte-integrity and JSON/XML parsing checks, including the catalogue’s specified event discriminators. This is not a complete vendor-schema validation or a tested detection.

For a simulation, first parse this fixture offline, then create a separately labelled synthetic variant and test it against the intended collector in an isolated lab. Never replay public example identities or destinations into production.
