Sysmon 7 — Image loaded

Sysmon 7 — Image loaded. Sysmon records image loaded through its Windows Operational channel.

sysmon xml endpoint process image-loaded

Source and collection

Microsoft-Windows-Sysmon/Operational; native XML export, not an EVTX binary file.

Install Sysmon and review the installed schema and filtering configuration. Use sysmon64 -s to inspect supported fields; preserve the deployed configuration version.

Validation boundaries

Image-load logging must be enabled; signature information can arrive asynchronously and is not a trust verdict.

This sample passed byte-integrity and JSON/XML parsing checks, including the catalogue’s specified event discriminators. This is not a complete vendor-schema validation or a tested detection.

For a simulation, first parse this fixture offline, then create a separately labelled synthetic variant and test it against the intended collector in an isolated lab. Never replay public example identities or destinations into production.
