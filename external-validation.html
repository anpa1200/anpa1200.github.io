External validation / a milestone for AIDebug

AIDebug accepted into REMnux.

A milestone for a tool I built: on October 7, 2026, REMnux maintainer Lenny Zeltser merged AIDebug's installation state into the malware-analysis toolkit. The integration shipped in an official REMnux provisioning release, and the official documentation credits Andrey Pautov and 1200km.com.

From a personal reverse-engineering project to accepted upstream integration. Below is the evidence behind that milestone, alongside other accepted contributions, published releases, and clearly dated repository signals.

Accepted upstream · released integration · official documentation

AIDebug is part of REMnux provisioning

Lenny Zeltser merged AIDebug's installation state into REMnux on 2026-10-07. The integration shipped in the official salt-states release v2026.41.4, published October 7, 2026. This is an accepted and released integration, not a pending submission.

REMnux's upstream documentation lists AIDebug under Use Artificial Intelligence and Statically Analyze Code / General, crediting Andrey Pautov and 1200km.com.

The released state installs 1200km-aidebug[ai] through pip and enables upgrades; it is not pinned to the original proposal's 3.0.0 version. The official documentation explains --offline and warns that configured remote AI services receive sample data.

Boundary: accepted upstream integration and documented authorship; no certification, security-audit, VM-image, runtime-testing, adoption-count, or feature-wide endorsement claim.

What the evidence does not measure

Current AIDebug clone events are recorded above for a specific GitHub traffic window. No PyPI download count, active-user count, or REMnux usage total was available. The older aggregate-only portfolio history cannot be attributed to AIDebug.

Zero GitHub issues were found across open and closed states at this check. That is not evidence of zero users or zero bugs. Stars, forks, package downloads, clone events and feedback are separate signals; none alone establishes unique active users or production deployment.
