Windows Defender Exclusion List Modified — Sigma Rule

Sigma rule 46a68649-f218-4f86-aea1-16a759d81820. Windows Defender Exclusion List Modified — Sigma Rule. Detects modifications to the Windows Defender exclusion registry key. This could indicate a potentially suspicious or even malicious activity by an attacker trying to add a new exclusion in order to bypass security.
