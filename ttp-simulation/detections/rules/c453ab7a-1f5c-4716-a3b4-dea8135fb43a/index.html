Registry Manipulation via WMI Stdregprov — Sigma Rule

Sigma rule c453ab7a-1f5c-4716-a3b4-dea8135fb43a. Registry Manipulation via WMI Stdregprov — Sigma Rule. Detects the usage of wmic.exe to modify Windows registry via the WMI StdRegProv class write methods (CreateKey, DeleteKey, SetStringValue, etc.). This behaviour could be potentially suspicious because it uses an alternative method to modify registry keys instead of legitimate registry tools like reg.exe or regedit.exe. Attackers specifically choose this technique to evade detection and bypass security monitoring focused on traditional registry modification commands.
