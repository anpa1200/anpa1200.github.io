Suspicious FileFix Execution Pattern — Sigma Rule

Sigma rule b5b29e4e-31fa-4fdf-b058-296e7a1aa0c2. Suspicious FileFix Execution Pattern — Sigma Rule. Detects suspicious FileFix execution patterns where users are tricked into running malicious commands through browser file upload dialog manipulation. This attack typically begins when users visit malicious websites impersonating legitimate services or news platforms, which may display fake CAPTCHA challenges or direct instructions to open file explorer and paste clipboard content. The clipboard content usually contains commands that download and execute malware, such as information stealing tools.
