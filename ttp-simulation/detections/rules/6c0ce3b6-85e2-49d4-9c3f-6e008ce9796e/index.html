Suspicious Deno File Written from Remote Source — Sigma Rule

Sigma rule 6c0ce3b6-85e2-49d4-9c3f-6e008ce9796e. Suspicious Deno File Written from Remote Source — Sigma Rule. Detects Deno writing a file from a direct HTTP(s) call and writing to the appdata folder or bringing it's own malicious DLL. This behavior may indicate an attempt to execute remotely hosted, potentially malicious files through deno.
