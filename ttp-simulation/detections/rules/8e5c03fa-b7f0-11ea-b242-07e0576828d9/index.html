Denied Access To Remote Desktop — Sigma Rule

Sigma rule 8e5c03fa-b7f0-11ea-b242-07e0576828d9. Denied Access To Remote Desktop — Sigma Rule. This event is generated when an authenticated user who is not allowed to log on remotely attempts to connect to this computer through Remote Desktop. Often, this event can be generated by attackers when searching for available windows servers in the network.
