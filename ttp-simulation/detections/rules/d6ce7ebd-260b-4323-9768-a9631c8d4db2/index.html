RestrictedAdminMode Registry Value Tampering — Sigma Rule

Sigma rule d6ce7ebd-260b-4323-9768-a9631c8d4db2. RestrictedAdminMode Registry Value Tampering — Sigma Rule. Detects changes to the "DisableRestrictedAdmin" registry value in order to disable or enable RestrictedAdmin mode. RestrictedAdmin mode prevents the transmission of reusable credentials to the remote system to which you connect using Remote Desktop. This prevents your credentials from being harvested during the initial connection process if the remote server has been compromise
