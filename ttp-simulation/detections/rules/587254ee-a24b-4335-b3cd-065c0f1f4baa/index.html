Remote File Download Via Findstr.EXE — Sigma Rule

Sigma rule 587254ee-a24b-4335-b3cd-065c0f1f4baa. Remote File Download Via Findstr.EXE — Sigma Rule. Detects execution of "findstr" with specific flags and a remote share path. This specific set of CLI flags would allow "findstr" to download the content of the file located on the remote share as described in the LOLBAS entry.

    selection_cli_download_1:

    selection_cli_download_2:
        CommandLine|contains|windash: ' -l '
    selection_cli_download_3:
        CommandLine|contains: '\\\\'
    condition: selection_findstr and all of selection_cli_download_*
