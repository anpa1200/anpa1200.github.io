Virtualbox Driver Installation or Starting of VMs — Sigma Rule

Sigma rule bab049ca-7471-4828-9024-38279a4c04da. Virtualbox Driver Installation or Starting of VMs — Sigma Rule. Adversaries can carry out malicious operations using a virtual instance to avoid detection. This rule is built to detect the registration of the Virtualbox driver or start of a Virtualbox VM.
