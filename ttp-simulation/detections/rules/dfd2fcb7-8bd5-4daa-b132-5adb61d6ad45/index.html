Windows Hotfix Updates Reconnaissance Via Wmic.EXE — Sigma Rule

Sigma rule dfd2fcb7-8bd5-4daa-b132-5adb61d6ad45. Windows Hotfix Updates Reconnaissance Via Wmic.EXE — Sigma Rule. Detects the execution of wmic with the "qfe" flag in order to obtain information about installed hotfix updates on the system. This is often used by pentester and attacker enumeration scripts
