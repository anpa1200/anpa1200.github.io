Sigma rule 32438676-1dba-4ac7-bf69-b86cba995e05. GCP Access Policy Deleted — Sigma Rule. Detects when an access policy that is applied to a GCP cloud resource is deleted. An adversary would be able to remove access policies to gain access to a GCP cloud resource.
