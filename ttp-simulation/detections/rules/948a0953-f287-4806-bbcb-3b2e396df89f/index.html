Unsigned Mfdetours.DLL Sideloading — Sigma Rule

Sigma rule 948a0953-f287-4806-bbcb-3b2e396df89f. Unsigned Mfdetours.DLL Sideloading — Sigma Rule. Detects DLL sideloading of unsigned "mfdetours.dll". Executing "mftrace.exe" can be abused to attach to an arbitrary process and force load any DLL named "mfdetours.dll" from the current directory of execution.
