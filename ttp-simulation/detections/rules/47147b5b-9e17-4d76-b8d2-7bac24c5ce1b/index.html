Potential Browser Data Stealing — Sigma Rule

Sigma rule 47147b5b-9e17-4d76-b8d2-7bac24c5ce1b. Potential Browser Data Stealing — Sigma Rule. Adversaries may acquire credentials from web browsers by reading files specific to the target browser. Web browsers commonly save credentials such as website usernames and passwords so that they do not need to be entered manually in the future. Web browsers typically store the credentials in an encrypted format within a credential store.
