RestrictedAdminMode Registry Value Tampering - ProcCreation — Sigma Rule

Sigma rule 28ac00d6-22d9-4a3c-927f-bbd770104573. RestrictedAdminMode Registry Value Tampering - ProcCreation — Sigma Rule. Detects changes to the "DisableRestrictedAdmin" registry value in order to disable or enable RestrictedAdmin mode. RestrictedAdmin mode prevents the transmission of reusable credentials to the remote system to which you connect using Remote Desktop. This prevents your credentials from being harvested during the initial connection process if the remote server has been compromise
