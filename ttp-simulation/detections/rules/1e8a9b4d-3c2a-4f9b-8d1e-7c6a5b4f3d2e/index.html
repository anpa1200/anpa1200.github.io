PowerShell Defender Threat Severity Default Action Set to 'Allow' or 'NoAction' — Sigma Rule

Sigma rule 1e8a9b4d-3c2a-4f9b-8d1e-7c6a5b4f3d2e. PowerShell Defender Threat Severity Default Action Set to 'Allow' or 'NoAction' — Sigma Rule. Detects the use of PowerShell to execute the 'Set-MpPreference' cmdlet to configure Windows Defender's threat severity default action to 'Allow' (value '6') or 'NoAction' (value '9'). This is a highly suspicious configuration change that effectively disables Defender's ability to automatically mitigate threats of a certain severity level. An attacker might use this technique via the command line to bypass defenses before executing payloads.
