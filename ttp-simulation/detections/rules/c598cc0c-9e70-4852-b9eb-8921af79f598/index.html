Hacktool - EDR-Freeze Execution — Sigma Rule

Sigma rule c598cc0c-9e70-4852-b9eb-8921af79f598. Hacktool - EDR-Freeze Execution — Sigma Rule. Detects execution of EDR-Freeze, a tool that exploits the MiniDumpWriteDump function and WerFaultSecure.exe to suspend EDR and Antivirus processes on Windows. EDR-Freeze leverages a race-condition attack to put security processes into a dormant state by suspending WerFaultSecure at the moment it freezes the target process. This technique does not require kernel-level exploits or BYOVD, but instead abuses user-mode functionality to temporarily disable monitoring by EDR or Antimalware solutions.
