Application Using Device Code Authentication Flow — Sigma Rule

Sigma rule 248649b7-d64f-46f0-9fb2-a52774166fb5. Application Using Device Code Authentication Flow — Sigma Rule. Device code flow is an OAuth 2.0 protocol flow specifically for input constrained devices and is not used in all environments. If this type of flow is seen in the environment and not being used in an input constrained device scenario, further investigation is warranted. This can be a misconfigured application or potentially something malicious.
