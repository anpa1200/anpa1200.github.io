Python One-Liners with Base64 Decoding - Linux — Sigma Rule

Sigma rule 55e862a8-dd9c-4651-807a-f21fcad56716. Python One-Liners with Base64 Decoding - Linux — Sigma Rule. Detects the use of Python's base64 decoding functions in command line executions on Linux systems. Malicious scripts often use python one-liners to decode and execute base64-encoded payloads, which is a common technique for obfuscation and evasion.
