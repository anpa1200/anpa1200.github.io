System Owner or User Discovery - Linux — Sigma Rule

Sigma rule 9a0d8ca0-2385-4020-b6c6-cb6153ca56f3. System Owner or User Discovery - Linux — Sigma Rule. Detects the execution of host or user discovery utilities such as "whoami", "hostname", "id", etc. Adversaries may use the information from System Owner/User Discovery during automated discovery to shape follow-on behaviors, including whether or not the adversary fully infects the target and/or attempts specific actions.

detection:

            - 'last'
            - 'uname'
            - 'users'

    condition: selection
