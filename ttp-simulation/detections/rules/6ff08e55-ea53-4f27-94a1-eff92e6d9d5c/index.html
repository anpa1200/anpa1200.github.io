System Information Discovery Via Sysctl - MacOS — Sigma Rule

Sigma rule 6ff08e55-ea53-4f27-94a1-eff92e6d9d5c. System Information Discovery Via Sysctl - MacOS — Sigma Rule. Detects the execution of "sysctl" with specific arguments that have been used by threat actors and malware. It provides system hardware information. This process is primarily used to detect and avoid virtualization and analysis environments.
