Winlogon Notify Key Logon Persistence — Sigma Rule

Sigma rule bbf59793-6efb-4fa1-95ca-a7d288e52c88. Winlogon Notify Key Logon Persistence — Sigma Rule. Adversaries may abuse features of Winlogon to execute DLLs and/or executables when a user logs in. Winlogon.exe is a Windows component responsible for actions at logon/logoff as well as the secure attention sequence (SAS) triggered by Ctrl-Alt-Delete.
