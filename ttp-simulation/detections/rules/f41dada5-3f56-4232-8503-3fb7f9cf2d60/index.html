ESXi Storage Information Discovery Via ESXCLI — Sigma Rule

Sigma rule f41dada5-3f56-4232-8503-3fb7f9cf2d60. ESXi Storage Information Discovery Via ESXCLI — Sigma Rule. Detects execution of the "esxcli" command with the "storage" flag in order to retrieve information about the storage status and other related information. Seen used by malware such as DarkSide and LockBit.
