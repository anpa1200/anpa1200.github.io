Windows Defender Exclusion Registry Key - Write Access Requested — Sigma Rule

Sigma rule e9c8808f-4cfb-4ba9-97d4-e5f3beaa244d. Windows Defender Exclusion Registry Key - Write Access Requested — Sigma Rule. Detects write access requests to the Windows Defender exclusions registry keys. This could be an indication of an attacker trying to request a handle or access the object to write new exclusions in order to bypass security.
