Potential Hidden Directory Creation Via NTFS INDEX_ALLOCATION Stream — Sigma Rule

Sigma rule a8f866e1-bdd4-425e-a27a-37619238d9c7. Potential Hidden Directory Creation Via NTFS INDEX_ALLOCATION Stream — Sigma Rule. Detects the creation of hidden file/folder with the "::$index_allocation" stream. Which can be used as a technique to prevent access to folder and files from tooling such as "explorer.exe" and "powershell.exe"
