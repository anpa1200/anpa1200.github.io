Execution DLL of Choice Using WAB.EXE — Sigma Rule

Sigma rule fc014922-5def-4da9-a0fc-28c973f41bfb. Execution DLL of Choice Using WAB.EXE — Sigma Rule. This rule detects that the path to the DLL written in the registry is different from the default one. Launched WAB.exe tries to load the DLL from Registry.
