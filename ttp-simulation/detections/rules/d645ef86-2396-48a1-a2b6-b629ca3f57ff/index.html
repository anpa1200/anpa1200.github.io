Windows Credential Guard Related Registry Value Deleted - Registry — Sigma Rule

Sigma rule d645ef86-2396-48a1-a2b6-b629ca3f57ff. Windows Credential Guard Related Registry Value Deleted - Registry — Sigma Rule. Detects attempts to disable Windows Credential Guard by deleting registry values. Credential Guard uses virtualization-based security to isolate secrets so that only privileged system software can access them. Adversaries may disable Credential Guard to gain access to sensitive credentials stored in the system, such as NTLM hashes and Kerberos tickets, which can be used for lateral movement and privilege escalation.
