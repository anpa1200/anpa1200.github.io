HackTool - Windows Credential Editor (WCE) Execution — Sigma Rule

Sigma rule 7aa7009a-28b9-4344-8c1f-159489a390df. HackTool - Windows Credential Editor (WCE) Execution — Sigma Rule. Detects the use of Windows Credential Editor (WCE), a popular post-exploitation tool used to extract plaintext passwords, hash, PIN code and Kerberos tickets from memory. It is often used by threat actors for credential dumping and lateral movement within compromised networks.
