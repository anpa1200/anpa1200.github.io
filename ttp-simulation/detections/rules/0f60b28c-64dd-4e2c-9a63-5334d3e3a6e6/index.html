Script Interpreter Spawning Credential Scanner - Windows — Sigma Rule

Sigma rule 0f60b28c-64dd-4e2c-9a63-5334d3e3a6e6. Script Interpreter Spawning Credential Scanner - Windows — Sigma Rule. Detects a script interpreter process (like node.js or bun) spawning a known credential scanning tool (e.g., trufflehog, gitleaks). This behavior is indicative of an attempt to find and steal secrets, as seen in the "Shai-Hulud: The Second Coming" campaign.
