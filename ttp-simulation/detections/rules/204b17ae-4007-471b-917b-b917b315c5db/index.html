Greedy File Deletion Using Del — Sigma Rule

Sigma rule 204b17ae-4007-471b-917b-b917b315c5db. Greedy File Deletion Using Del — Sigma Rule. Detects execution of the "del" builtin command to remove files using greedy/wildcard expression. This is often used by malware to delete content of folders that perhaps contains the initial malware infection or to delete evidence.
