Activity from Suspicious IP Addresses — Sigma Rule

Sigma rule a3501e8e-af9e-43c6-8cd6-9360bdaae498. Activity from Suspicious IP Addresses — Sigma Rule. Detects when a Microsoft Cloud App Security reported users were active from an IP address identified as risky by Microsoft Threat Intelligence. These IP addresses are involved in malicious activities, such as Botnet C&C, and may indicate compromised account.
