Potential ReflectDebugger Content Execution Via WerFault.EXE — Sigma Rule

Sigma rule fabfb3a7-3ce1-4445-9c7c-3c27f1051cdd. Potential ReflectDebugger Content Execution Via WerFault.EXE — Sigma Rule. Detects execution of "WerFault.exe" with the "-pr" commandline flag that is used to run files stored in the ReflectDebugger key which could be used to store the path to the malware in order to masquerade the execution flow
