File Decoded From Base64/Hex Via Certutil.EXE — Sigma Rule

Sigma rule cc9cbe82-7bc0-4ef5-bc23-bbfb83947be7. File Decoded From Base64/Hex Via Certutil.EXE — Sigma Rule. Detects the execution of certutil with either the "decode" or "decodehex" flags to decode base64 or hex encoded files. This can be abused by attackers to decode an encoded payload before execution
