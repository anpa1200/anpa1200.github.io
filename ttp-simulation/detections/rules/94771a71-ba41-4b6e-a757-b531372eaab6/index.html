File Download From Browser Process Via Inline URL — Sigma Rule

Sigma rule 94771a71-ba41-4b6e-a757-b531372eaab6. File Download From Browser Process Via Inline URL — Sigma Rule. Detects execution of a browser process with a URL argument pointing to a file with a potentially interesting extension. This can be abused to download arbitrary files or to hide from the user for example by launching the browser in a minimized state.
