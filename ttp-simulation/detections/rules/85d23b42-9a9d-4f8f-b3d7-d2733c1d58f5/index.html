HackTool - HollowReaper Execution — Sigma Rule

Sigma rule 85d23b42-9a9d-4f8f-b3d7-d2733c1d58f5. HackTool - HollowReaper Execution — Sigma Rule. Detects usage of HollowReaper, a process hollowing shellcode launcher used for stealth payload execution through process hollowing. It replaces the memory of a legitimate process with custom shellcode, allowing the attacker to execute payloads under the guise of trusted binaries.
