Powerview Add-DomainObjectAcl DCSync AD Extend Right — Sigma Rule

Sigma rule 2c99737c-585d-4431-b61a-c911d86ff32f. Powerview Add-DomainObjectAcl DCSync AD Extend Right — Sigma Rule. Backdooring domain object to grant the rights associated with DCSync to a regular user or machine account using Powerview\Add-DomainObjectAcl DCSync Extended Right cmdlet, will allow to re-obtain the pwd hashes of any user/computer
