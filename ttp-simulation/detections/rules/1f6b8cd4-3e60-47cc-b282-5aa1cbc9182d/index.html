Remote Access Tool - Team Viewer Session Started On Linux Host — Sigma Rule

Sigma rule 1f6b8cd4-3e60-47cc-b282-5aa1cbc9182d. Remote Access Tool - Team Viewer Session Started On Linux Host — Sigma Rule. Detects the command line executed when TeamViewer starts a session started by a remote host. Once a connection has been started, an investigator can verify the connection details by viewing the "incoming_connections.txt" log file in the TeamViewer folder.
