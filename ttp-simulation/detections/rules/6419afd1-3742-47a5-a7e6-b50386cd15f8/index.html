Chmod Targeting Sensitive Directories — Sigma Rule

Sigma rule 6419afd1-3742-47a5-a7e6-b50386cd15f8. Chmod Targeting Sensitive Directories — Sigma Rule. Detects chmod targeting files in sensitive directory paths on Linux systems. Attackers may use chmod to change permissions of files in these directories to maintain persistence, escalate privileges, or disrupt system operations.
