Audit CVE Event — Sigma Rule

Sigma rule 48d91a3a-2363-43ba-a456-ca71ac3da5c2. Audit CVE Event — Sigma Rule. Detects events generated by user-mode applications when they call the CveEventWrite API when a known vulnerability is trying to be exploited. MS started using this log in Jan. 2020 with CVE-2020-0601 (a Windows CryptoAPI vulnerability. Unfortunately, that is about the only instance of CVEs being written to this log.
