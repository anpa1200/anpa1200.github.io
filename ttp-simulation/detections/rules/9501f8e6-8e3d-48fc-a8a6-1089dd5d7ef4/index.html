Network Connection Initiated To DevTunnels Domain — Sigma Rule

Sigma rule 9501f8e6-8e3d-48fc-a8a6-1089dd5d7ef4. Network Connection Initiated To DevTunnels Domain — Sigma Rule. Detects network connections to Devtunnels domains initiated by a process on a system. Attackers can abuse that feature to establish a reverse shell or persistence on a machine.
