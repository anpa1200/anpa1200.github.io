Sigma rule cb0fe7c5-f3a3-484d-aa25-d350a7912729. Suspicious Driver/DLL Installation Via Odbcconf.EXE — Sigma Rule. Detects execution of "odbcconf" with the "INSTALLDRIVER" action where the driver doesn't contain a ".dll" extension. This is often used as a defense evasion method.
