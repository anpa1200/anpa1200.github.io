DCERPC SMB Spoolss Named Pipe — Sigma Rule

Sigma rule 214e8f95-100a-4e04-bb31-ef6cba8ce07e. DCERPC SMB Spoolss Named Pipe — Sigma Rule. Detects the use of the spoolss named pipe over SMB. This can be used to trigger the authentication via NTLM of any machine that has the spoolservice enabled.
