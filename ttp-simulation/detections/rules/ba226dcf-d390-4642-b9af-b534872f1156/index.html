Windows Event Log Access Tampering Via Registry — Sigma Rule

Sigma rule ba226dcf-d390-4642-b9af-b534872f1156. Windows Event Log Access Tampering Via Registry — Sigma Rule. Detects changes to the Windows EventLog channel permission values. It focuses on changes to the Security Descriptor Definition Language (SDDL) string, as modifications to these values can restrict access to specific users or groups, potentially aiding in defense evasion by controlling who can view or modify a event log channel. Upon execution, the user shouldn't be able to access the event log channel via the event viewer or via utilities such as "Get-EventLog" or "wevtutil".
