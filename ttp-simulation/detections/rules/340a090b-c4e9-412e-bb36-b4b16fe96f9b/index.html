Renamed ZOHO Dctask64 Execution — Sigma Rule

Sigma rule 340a090b-c4e9-412e-bb36-b4b16fe96f9b. Renamed ZOHO Dctask64 Execution — Sigma Rule. Detects a renamed "dctask64.exe" execution, a signed binary by ZOHO Corporation part of ManageEngine Endpoint Central. This binary can be abused for DLL injection, arbitrary command and process execution.
