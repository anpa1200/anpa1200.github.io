Sigma rule 97a80ec7-0e2f-4d05-9ef4-65760e634f6b. Security Privileges Enumeration Via Whoami.EXE — Sigma Rule. Detects a whoami.exe executed with the /priv command line flag instructing the tool to show all current user privileges. This is often used after a privilege escalation attempt.
