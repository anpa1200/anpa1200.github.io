Github Outside Collaborator Detected — Sigma Rule

Sigma rule eaa9ac35-1730-441f-9587-25767bde99d7. Github Outside Collaborator Detected — Sigma Rule. Detects when an organization member or an outside collaborator is added to or removed from a project board or has their permission level changed or when an owner removes an outside collaborator from an organization or when two-factor authentication is required in an organization and an outside collaborator does not use 2FA or disables 2FA.
