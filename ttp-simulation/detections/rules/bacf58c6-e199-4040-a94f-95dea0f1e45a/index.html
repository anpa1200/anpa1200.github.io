Windows Filtering Platform Blocked Connection From EDR Agent Binary — Sigma Rule

Sigma rule bacf58c6-e199-4040-a94f-95dea0f1e45a. Windows Filtering Platform Blocked Connection From EDR Agent Binary — Sigma Rule. Detects a Windows Filtering Platform (WFP) blocked connection event involving common Endpoint Detection and Response (EDR) agents. Adversaries may use WFP filters to prevent Endpoint Detection and Response (EDR) agents from reporting security events.
