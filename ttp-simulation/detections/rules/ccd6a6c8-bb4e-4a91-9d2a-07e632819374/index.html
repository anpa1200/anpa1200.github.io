AWS SAML Provider Deletion Activity — Sigma Rule

Sigma rule ccd6a6c8-bb4e-4a91-9d2a-07e632819374. AWS SAML Provider Deletion Activity — Sigma Rule. Detects the deletion of an AWS SAML provider, potentially indicating malicious intent to disrupt administrative or security team access. An attacker can remove the SAML provider for the information security team or a team of system administrators, to make it difficult for them to work and investigate at the time of the attack and after it.
