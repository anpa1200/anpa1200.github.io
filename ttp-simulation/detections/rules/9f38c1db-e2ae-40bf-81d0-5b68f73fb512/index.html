Suspicious BitLocker Access Agent Update Utility Execution — Sigma Rule

Sigma rule 9f38c1db-e2ae-40bf-81d0-5b68f73fb512. Suspicious BitLocker Access Agent Update Utility Execution — Sigma Rule. Detects the execution of the BitLocker Access Agent Update Utility (baaupdate.exe) which is not a common parent process for other processes. Suspicious child processes spawned by baaupdate.exe could indicate an attempt at lateral movement via BitLocker DCOM & COM Hijacking.
