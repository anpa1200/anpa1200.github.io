Antivirus Web Shell Detection — Sigma Rule

Sigma rule fdf135a2-9241-4f96-a114-bb404948f736. Antivirus Web Shell Detection — Sigma Rule. Detects a highly relevant Antivirus alert that reports a web shell. It's highly recommended to tune this rule to the specific strings used by your anti virus solution by downloading a big WebShell repository from e.g. github and checking the matches. This event must not be ignored just because the AV has blocked the malware but investigate, how it came there in the first place.
