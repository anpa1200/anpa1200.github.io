AWS Key Pair Import Activity — Sigma Rule

Sigma rule 92f84194-8d9a-4ee0-8699-c30bfac59780. AWS Key Pair Import Activity — Sigma Rule. Detects the import of SSH key pairs into AWS EC2, which may indicate an attacker attempting to gain unauthorized access to instances. This activity could lead to initial access, persistence, or privilege escalation, potentially compromising sensitive data and operations.

False positives
