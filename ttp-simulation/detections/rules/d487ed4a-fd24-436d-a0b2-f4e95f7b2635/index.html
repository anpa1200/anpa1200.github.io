Suspicious ClickFix/FileFix Execution Pattern — Sigma Rule

Sigma rule d487ed4a-fd24-436d-a0b2-f4e95f7b2635. Suspicious ClickFix/FileFix Execution Pattern — Sigma Rule. Detects suspicious execution patterns where users are tricked into running malicious commands via clipboard manipulation, either through the Windows Run dialog (ClickFix) or File Explorer address bar (FileFix). Attackers leverage social engineering campaigns—such as fake CAPTCHA challenges or urgent alerts—encouraging victims to paste clipboard contents, often executing mshta.exe, powershell.exe, or similar commands to infect systems.
