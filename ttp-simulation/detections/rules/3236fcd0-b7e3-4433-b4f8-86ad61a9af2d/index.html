PowerShell Download Via Net.WebClient - PowerShell Classic — Sigma Rule

Sigma rule 3236fcd0-b7e3-4433-b4f8-86ad61a9af2d. PowerShell Download Via Net.WebClient - PowerShell Classic — Sigma Rule. Detects PowerShell download activity, via the .DownloadFile() or .DownloadString() methods of the Net.WebClient class. This technique is often abused by attackers to download additional payloads.
