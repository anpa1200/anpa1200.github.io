Windows Recall Feature Enabled Via Reg.EXE — Sigma Rule

Sigma rule 817f252c-5143-4dae-b418-48c3e9f63728. Windows Recall Feature Enabled Via Reg.EXE — Sigma Rule. Detects the enabling of the Windows Recall feature via registry manipulation. Windows Recall can be enabled by deleting the existing "DisableAIDataAnalysis" value, or setting it to 0. Adversaries may enable Windows Recall as part of post-exploitation discovery and collection activities. This rule assumes that Recall is already explicitly disabled on the host, and subsequently enabled by the adversary.
