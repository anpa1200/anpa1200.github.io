Application Termination Attempt via Wmic.EXE — Sigma Rule

Sigma rule 49d9671b-0a0a-4c09-8280-d215bfd30662. Application Termination Attempt via Wmic.EXE — Sigma Rule. Detects an attempt to terminate a process via "wmic" with the "call terminate" flag. Adversaries may use wmic to terminate security products or other applications on the compromised host. This event is triggered on on attempt and process creation can be either successful or unsuccessful.
