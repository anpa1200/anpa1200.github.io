Boot Configuration Tampering Via Bcdedit.EXE — Sigma Rule

Sigma rule 1444443e-6757-43e4-9ea4-c8fc705f79a2. Boot Configuration Tampering Via Bcdedit.EXE — Sigma Rule. Detects the use of the bcdedit command to tamper with the boot configuration data. This technique is often times used by malware or attackers as a destructive way before launching ransomware.
