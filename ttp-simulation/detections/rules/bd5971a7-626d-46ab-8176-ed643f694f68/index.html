Extracting Information with PowerShell — Sigma Rule

Sigma rule bd5971a7-626d-46ab-8176-ed643f694f68. Extracting Information with PowerShell — Sigma Rule. Adversaries may search local file systems and remote file shares for files containing insecurely stored credentials. These can be files created by users to store their own credentials, shared credential stores for a group of individuals, configuration files containing passwords for a system or service, or source code/binary files containing embedded passwords.
