Potential Persistence Via AppCompat RegisterAppRestart Layer — Sigma Rule

Sigma rule b86852fb-4c77-48f9-8519-eb1b2c308b59. Potential Persistence Via AppCompat RegisterAppRestart Layer — Sigma Rule. Detects the setting of the REGISTERAPPRESTART compatibility layer on an application. This compatibility layer allows an application to register for restart using the "RegisterApplicationRestart" API. This can be potentially abused as a persistence mechanism.
