Malicious PE Execution by Microsoft Visual Studio Debugger — Sigma Rule

Sigma rule 15c7904e-6ad1-4a45-9b46-5fb25df37fd2. Malicious PE Execution by Microsoft Visual Studio Debugger — Sigma Rule. There is an option for a MS VS Just-In-Time Debugger "vsjitdebugger.exe" to launch specified executable and attach a debugger. This option may be used adversaries to execute malicious code by signed verified binary. The debugger is installed alongside with Microsoft Visual Studio package.
