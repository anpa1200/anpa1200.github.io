Potential Remote Desktop Tunneling — Sigma Rule

Sigma rule 8a3038e8-9c9d-46f8-b184-66234a160f6f. Potential Remote Desktop Tunneling — Sigma Rule. Detects potential use of an SSH utility to establish RDP over a reverse SSH Tunnel. This can be used by attackers to enable routing of network packets that would otherwise not reach their intended destination.

id: 8a3038e8-9c9d-46f8-b184-66234a160f6f

logsource:
    category: process_creation
    product: windows
detection:
    selection:
        CommandLine|contains: ':3389' # RDP port and usual SSH tunneling related switches in command line
    selection_opt:
        CommandLine|contains:
            - ' -L '
            - ' -P '
            - ' -R '
            - ' -pw '
            - ' -ssh '
    condition: all of selection*
falsepositives:
    - Unknown
level: medium
