Access to Browser Login Data — Sigma Rule

Sigma rule fc028194-969d-4122-8abe-0470d5b8f12f. Access to Browser Login Data — Sigma Rule. Adversaries may acquire credentials from web browsers by reading files specific to the target browser. Web browsers commonly save credentials such as website usernames and passwords so that they do not need to be entered manually in the future. Web browsers typically store the credentials in an encrypted format within a credential store.
