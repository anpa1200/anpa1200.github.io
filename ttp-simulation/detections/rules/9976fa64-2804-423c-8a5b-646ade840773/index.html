Suspicious Outbound SMTP Connections — Sigma Rule

Sigma rule 9976fa64-2804-423c-8a5b-646ade840773. Suspicious Outbound SMTP Connections — Sigma Rule. Adversaries may steal data by exfiltrating it over an un-encrypted network protocol other than that of the existing command and control channel. The data may also be sent to an alternate network location from the main command and control server.
