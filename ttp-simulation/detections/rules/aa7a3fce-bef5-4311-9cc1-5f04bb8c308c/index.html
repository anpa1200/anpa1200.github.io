Certificate Exported Via PowerShell - ScriptBlock — Sigma Rule

Sigma rule aa7a3fce-bef5-4311-9cc1-5f04bb8c308c. Certificate Exported Via PowerShell - ScriptBlock — Sigma Rule. Detects calls to cmdlets inside of PowerShell scripts that are used to export certificates from the local certificate store. Threat actors were seen abusing this to steal private keys from compromised machines.

title: Certificate Exported Via PowerShell - ScriptBlock

tags:
    - attack.credential-access
    - attack.t1552.004
logsource:
    product: windows
    category: ps_script
    definition: 'Requirements: Script Block Logging must be enabled'
detection:
    selection:
        ScriptBlockText|contains:
            - 'Export-PfxCertificate'
            - 'Export-Certificate'
    filter_optional_module_export:
        ScriptBlockText|contains: 'CmdletsToExport = @('
    condition: selection and not 1 of filter_optional_*
falsepositives:
    - Legitimate certificate exports by administrators. Additional filters might be required.
level: medium
