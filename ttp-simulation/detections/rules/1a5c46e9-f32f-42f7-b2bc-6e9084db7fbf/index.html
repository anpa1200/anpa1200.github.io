Trust Access Disable For VBApplications — Sigma Rule

Sigma rule 1a5c46e9-f32f-42f7-b2bc-6e9084db7fbf. Trust Access Disable For VBApplications — Sigma Rule. Detects registry changes to Microsoft Office "AccessVBOM" to a value of "1" which disables trust access for VBA on the victim machine and lets attackers execute malicious macros without any Microsoft Office warnings.
