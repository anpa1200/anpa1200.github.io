AWS Route 53 Domain Transfer Lock Disabled — Sigma Rule

Sigma rule 3940b5f1-3f46-44aa-b746-ebe615b879e0. AWS Route 53 Domain Transfer Lock Disabled — Sigma Rule. Detects when a transfer lock was removed from a Route 53 domain. It is recommended to refrain from performing this action unless intending to transfer the domain to a different registrar.
