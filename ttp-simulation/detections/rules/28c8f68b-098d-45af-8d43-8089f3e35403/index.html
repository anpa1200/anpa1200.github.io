Potential Register_App.Vbs LOLScript Abuse — Sigma Rule

Sigma rule 28c8f68b-098d-45af-8d43-8089f3e35403. Potential Register_App.Vbs LOLScript Abuse — Sigma Rule. Detects potential abuse of the "register_app.vbs" script that is part of the Windows SDK. The script offers the capability to register new VSS/VDS Provider as a COM+ application. Attackers can use this to install malicious DLLs for persistence and execution.
