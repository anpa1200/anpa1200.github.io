Suspicious Loading of Dbgcore/Dbghelp DLLs from Uncommon Location — Sigma Rule

Sigma rule 416bc4a2-7217-4519-8dc7-c3271817f1d5. Suspicious Loading of Dbgcore/Dbghelp DLLs from Uncommon Location — Sigma Rule. Detects loading of dbgcore.dll or dbghelp.dll from uncommon locations such as user directories. These DLLs contain the MiniDumpWriteDump function, which can be abused for credential dumping purposes or in some cases for evading EDR/AV detection by suspending processes.

        Image|contains:
            - ':\Perflogs\'

            - '\Documents\'

            - '\Pictures\'

    selection_dll:
        ImageLoaded|endswith:
            - '\dbgcore.dll'
            - '\dbghelp.dll'
    condition: all of selection_*
