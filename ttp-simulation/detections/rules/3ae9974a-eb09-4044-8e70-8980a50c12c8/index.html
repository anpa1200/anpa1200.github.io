Suspicious Explorer Process with Whitespace Padding - ClickFix/FileFix — Sigma Rule

Sigma rule 3ae9974a-eb09-4044-8e70-8980a50c12c8. Suspicious Explorer Process with Whitespace Padding - ClickFix/FileFix — Sigma Rule. Detects process creation with suspicious whitespace padding followed by a '#' character, which may indicate ClickFix or FileFix techniques used to conceal malicious commands from visual inspection. ClickFix and FileFix are social engineering attack techniques where adversaries distribute phishing documents or malicious links that deceive users into opening the Windows Run dialog box or File Explorer search bar. The victims are then instructed to paste commands from their clipboard, which contain extensive whitespace padding using various Unicode space characters to push the actual malicious command far to the right, effectively hiding it from immediate view.
