PST Export Alert Using New-ComplianceSearchAction — Sigma Rule

Sigma rule 6897cd82-6664-11ed-9022-0242ac120002. PST Export Alert Using New-ComplianceSearchAction — Sigma Rule. Alert when a user has performed an export to a search using 'New-ComplianceSearchAction' with the '-Export' flag. This detection will detect PST export even if the 'eDiscovery search or exported' alert is disabled in the O365.This rule will apply to ExchangePowerShell usage and from the cloud.
