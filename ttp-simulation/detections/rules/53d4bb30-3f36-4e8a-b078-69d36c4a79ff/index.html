COM Object Execution via Xwizard.EXE — Sigma Rule

Sigma rule 53d4bb30-3f36-4e8a-b078-69d36c4a79ff. COM Object Execution via Xwizard.EXE — Sigma Rule. Detects the execution of Xwizard tool with the "RunWizard" flag and a GUID like argument. This utility can be abused in order to run custom COM object created in the registry.
