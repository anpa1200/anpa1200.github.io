Certificate Exported Via PowerShell — Sigma Rule

Sigma rule 9e716b33-63b2-46da-86a4-bd3c3b9b5dfb. Certificate Exported Via PowerShell — Sigma Rule. Detects calls to cmdlets that are used to export certificates from the local certificate store. Threat actors were seen abusing this to steal private keys from compromised machines.
