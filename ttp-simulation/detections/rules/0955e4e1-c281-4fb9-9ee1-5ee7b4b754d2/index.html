Use of Pcalua For Execution — Sigma Rule

Sigma rule 0955e4e1-c281-4fb9-9ee1-5ee7b4b754d2. Use of Pcalua For Execution — Sigma Rule. Detects execition of commands and binaries from the context of The program compatibility assistant (Pcalua.exe). This can be used as a LOLBIN in order to bypass application whitelisting.

        Image|endswith: '\pcalua.exe'
        CommandLine|contains: ' -a' # No space after the flag because it accepts anything as long as there a "-a"
    condition: selection
