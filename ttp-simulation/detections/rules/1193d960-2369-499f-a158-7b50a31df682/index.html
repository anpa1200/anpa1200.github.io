Potential Suspicious Browser Launch From Document Reader Process — Sigma Rule

Sigma rule 1193d960-2369-499f-a158-7b50a31df682. Potential Suspicious Browser Launch From Document Reader Process — Sigma Rule. Detects when a browser process or browser tab is launched from an application that handles document files such as Adobe, Microsoft Office, etc. And connects to a web application over http(s), this could indicate a possible phishing attempt.
