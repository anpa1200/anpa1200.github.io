Write Protect For Storage Disabled — Sigma Rule

Sigma rule 75f7a0e2-7154-4c4d-9eae-5cdb4e0a5c13. Write Protect For Storage Disabled — Sigma Rule. Detects applications trying to modify the registry in order to disable any write-protect property for storage devices. This could be a precursor to a ransomware attack and has been an observed technique used by cypherpunk group.
