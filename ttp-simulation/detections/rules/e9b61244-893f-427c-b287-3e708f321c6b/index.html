Potential Privilege Escalation Using Symlink Between Osk and Cmd — Sigma Rule

Sigma rule e9b61244-893f-427c-b287-3e708f321c6b. Potential Privilege Escalation Using Symlink Between Osk and Cmd — Sigma Rule. Detects the creation of a symbolic link between "cmd.exe" and the accessibility on-screen keyboard binary (osk.exe) using "mklink". This technique provides an elevated command prompt to the user from the login screen without the need to log in.
