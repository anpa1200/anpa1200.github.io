Hiding User Account Via SpecialAccounts Registry Key — Sigma Rule

Sigma rule f8aebc67-a56d-4ec9-9fbe-7b0e8b7b4efd. Hiding User Account Via SpecialAccounts Registry Key — Sigma Rule. Detects modifications to the registry key "HKLM\Software\Microsoft\Windows NT\CurrentVersion\Winlogon\SpecialAccounts\Userlist" where the value is set to "0" in order to hide user account from being listed on the logon screen.
