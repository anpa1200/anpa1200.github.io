NET NGenAssemblyUsageLog Registry Key Tamper — Sigma Rule

Sigma rule 28036918-04d3-423d-91c0-55ecf99fb892. NET NGenAssemblyUsageLog Registry Key Tamper — Sigma Rule. Detects changes to the NGenAssemblyUsageLog registry key. .NET Usage Log output location can be controlled by setting the NGenAssemblyUsageLog CLR configuration knob in the Registry or by configuring an environment variable (as described in the next section). By simplify specifying an arbitrary value (e.g. fake output location or junk data) for the expected value, a Usage Log file for the .NET execution context will not be created.
