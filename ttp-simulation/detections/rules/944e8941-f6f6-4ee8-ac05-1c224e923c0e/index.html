Add Port Monitor Persistence in Registry — Sigma Rule

Sigma rule 944e8941-f6f6-4ee8-ac05-1c224e923c0e. Add Port Monitor Persistence in Registry — Sigma Rule. Adversaries may use port monitors to run an attacker supplied DLL during system boot for persistence or privilege escalation. A port monitor can be set through the AddMonitor API call to set a DLL to be loaded at startup.
