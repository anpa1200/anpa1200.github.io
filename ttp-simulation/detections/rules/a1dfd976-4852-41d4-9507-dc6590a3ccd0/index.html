Suspicious File Access to Browser Credential Storage — Sigma Rule

Sigma rule a1dfd976-4852-41d4-9507-dc6590a3ccd0. Suspicious File Access to Browser Credential Storage — Sigma Rule. Detects file access to browser credential storage paths by non-browser processes, which may indicate credential access attempts. Adversaries may attempt to access browser credential storage to extract sensitive information such as usernames and passwords or cookies. This behavior is often commonly observed in credential stealing malware.
