DNS Query by Finger Utility — Sigma Rule

Sigma rule c082c2b0-525b-4dbc-9a26-a57dc4692074. DNS Query by Finger Utility — Sigma Rule. Detects DNS queries made by the finger utility, which can be abused by threat actors to retrieve remote commands for execution on Windows devices. In one ClickFix malware campaign, adversaries leveraged the finger protocol to fetch commands from a remote server. Since the finger utility is not commonly used in modern Windows environments, its presence already raises suspicion. Investigating such DNS queries can also help identify potential malicious infrastructure used by threat actors for command and control (C2) communication.
