Loading of Kernel Module via Insmod — Sigma Rule

Sigma rule 106d7cbd-80ff-4985-b682-a7043e5acb72. Loading of Kernel Module via Insmod — Sigma Rule. Detects loading of kernel modules with insmod command. Loadable Kernel Modules (LKMs) are pieces of code that can be loaded and unloaded into the kernel upon demand. Adversaries may use LKMs to obtain persistence within the system or elevate the privileges.
