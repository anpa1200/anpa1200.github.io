DNS Query Request To OneLaunch Update Service — Sigma Rule

Sigma rule df68f791-ad95-447f-a271-640a0dab9cf8. DNS Query Request To OneLaunch Update Service — Sigma Rule. Detects DNS query requests to "update.onelaunch.com". This domain is associated with the OneLaunch adware application. When the OneLaunch application is installed it will attempt to get updates from this domain.

title: DNS Query Request To OneLaunch Update Service
id: df68f791-ad95-447f-a271-640a0dab9cf8
