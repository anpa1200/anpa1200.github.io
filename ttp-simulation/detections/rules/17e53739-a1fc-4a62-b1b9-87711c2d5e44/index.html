Python Function Execution Security Warning Disabled In Excel - Registry — Sigma Rule

Sigma rule 17e53739-a1fc-4a62-b1b9-87711c2d5e44. Python Function Execution Security Warning Disabled In Excel - Registry — Sigma Rule. Detects changes to the registry value "PythonFunctionWarnings" that would prevent any warnings or alerts from showing when Python functions are about to be executed. Threat actors could run malicious code through the new Microsoft Excel feature that allows Python to run within the spreadsheet.
