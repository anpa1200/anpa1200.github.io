Arbitrary Shell Command Execution Via Settingcontent-Ms — Sigma Rule

Sigma rule 24de4f3b-804c-4165-b442-5a06a2302c7e. Arbitrary Shell Command Execution Via Settingcontent-Ms — Sigma Rule. The .SettingContent-ms file type was introduced in Windows 10 and allows a user to create "shortcuts" to various Windows 10 setting pages. These files are simply XML and contain paths to various Windows 10 settings binaries.
