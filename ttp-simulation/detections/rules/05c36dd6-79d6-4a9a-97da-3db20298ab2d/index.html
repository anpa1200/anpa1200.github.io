XSL Script Execution Via WMIC.EXE — Sigma Rule

Sigma rule 05c36dd6-79d6-4a9a-97da-3db20298ab2d. XSL Script Execution Via WMIC.EXE — Sigma Rule. Detects the execution of WMIC with the "format" flag to potentially load local XSL files. Adversaries abuse this functionality to execute arbitrary files while potentially bypassing application whitelisting defenses. Extensible Stylesheet Language (XSL) files are commonly used to describe the processing and rendering of data within XML files.

        CommandLine|contains:
            - '://'
            - '\\\\'
    condition: all of selection_* and not 1 of filter_main_*
