Potential AMSI COM Server Hijacking — Sigma Rule

Sigma rule 160d2780-31f7-4922-8b3a-efce30e63e96. Potential AMSI COM Server Hijacking — Sigma Rule. Detects changes to the AMSI come server registry key in order disable AMSI scanning functionalities. When AMSI attempts to starts its COM component, it will query its registered CLSID and return a non-existent COM server. This causes a load failure and prevents any scanning methods from being accessed, ultimately rendering AMSI useless
