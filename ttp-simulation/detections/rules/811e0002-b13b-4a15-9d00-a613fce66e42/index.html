PUA - Process Hacker Execution — Sigma Rule

Sigma rule 811e0002-b13b-4a15-9d00-a613fce66e42. PUA - Process Hacker Execution — Sigma Rule. Detects the execution of Process Hacker based on binary metadata information (Image, Hash, Imphash, etc). Process Hacker is a tool to view and manipulate processes, kernel options and other low level options. Threat actors abused older vulnerable versions to manipulate system processes.
