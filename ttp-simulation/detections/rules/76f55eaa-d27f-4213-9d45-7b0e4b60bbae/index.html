Service Reconnaissance Via Wmic.EXE — Sigma Rule

Sigma rule 76f55eaa-d27f-4213-9d45-7b0e4b60bbae. Service Reconnaissance Via Wmic.EXE — Sigma Rule. An adversary might use WMI to check if a certain remote service is running on a remote device. When the test completes, a service information will be displayed on the screen if it exists. A common feedback message is that "No instance(s) Available" if the service queried is not running. A common error message is "Node - (provided IP or default) ERROR Description =The RPC server is unavailable" if the provided remote host is unreachable
