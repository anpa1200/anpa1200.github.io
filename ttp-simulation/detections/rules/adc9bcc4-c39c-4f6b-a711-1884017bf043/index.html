Network Sniffing - MacOs — Sigma Rule

Sigma rule adc9bcc4-c39c-4f6b-a711-1884017bf043. Network Sniffing - MacOs — Sigma Rule. Detects the usage of tooling to sniff network traffic. An adversary may place a network interface into promiscuous mode to passively access data in transit over the network, or use span ports to capture a larger amount of data.
