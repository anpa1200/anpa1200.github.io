Files Added To An Archive Using Rar.EXE — Sigma Rule

Sigma rule 6f3e2987-db24-4c78-a860-b4f4095a7095. Files Added To An Archive Using Rar.EXE — Sigma Rule. Detects usage of "rar" to add files to an archive for potential compression. An adversary may compress data (e.g. sensitive documents) that is collected prior to exfiltration in order to make it portable and minimize the amount of data sent over the network.
