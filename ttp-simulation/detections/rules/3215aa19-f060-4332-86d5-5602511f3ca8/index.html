Suspicious LNK Double Extension File Created — Sigma Rule

Sigma rule 3215aa19-f060-4332-86d5-5602511f3ca8. Suspicious LNK Double Extension File Created — Sigma Rule. Detects the creation of files with an "LNK" as a second extension. This is sometimes used by malware as a method to abuse the fact that Windows hides the "LNK" extension by default.
