Hiding User Account Via SpecialAccounts Registry Key - CommandLine — Sigma Rule

Sigma rule 9ec9fb1b-e059-4489-9642-f270c207923d. Hiding User Account Via SpecialAccounts Registry Key - CommandLine — Sigma Rule. Detects changes to the registry key "HKLM\Software\Microsoft\Windows NT\CurrentVersion\Winlogon\SpecialAccounts\Userlist" where the value is set to "0" in order to hide user account from being listed on the logon screen.
