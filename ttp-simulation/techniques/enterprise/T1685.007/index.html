Complete technique description

Adversaries may use methods like Indirect Prompt Injection to disrupt, disable, or otherwise impair autonomous defensive capabilities such as LLM-assisted processing of malware, artifacts, or activity.[Prompt Injection LLM-Powered SOC Assistants] This behavior may cause a system to ignore data, fail to alert on malicious activity, abort analysis, or to be disabled completely.

Adversaries may include content in malware implants that mimic an LLM prompt scaffold that contains fake system messages in order to convince the LLM that it has encountered an error.[MacOS.Gaslight Prompt Injection][Gaslight AI triage prompt injection] Depending on the type of error, the LLM may abort analysis, truncate, or refuse to continue. Adversaries may also embed prompts in malware intended to stop agents or systems from analyzing the malware.[Shai-Hulud May 2026]

Source-linked mitigations
  • M1018 User Account Management

    Run AI-assisted analysis services using dedicated identities with permissions limited to required analysis functions. Separate analysis authority from broader analyst, administrative, or production access.

  • M1022 Restrict File and Directory Permissions

    Limit AI-assisted analysis systems to the files and directories required for analysis and prevent artifacts under investigation from modifying agent configuration, instruction files, analysis state, or other trusted AI application resources.

  • M1026 Privileged Account Management

    Prevent AI-assisted analysis agents from exercising privileged capabilities solely as a consequence of artifact-derived instructions. Require independent authorization for privileged or consequential operations outside the expected analysis workflow.

  • M1038 Execution Prevention

    Prevent content contained within an artifact under analysis from directly controlling the analysis workflow, terminating analysis, altering required analysis stages, or initiating unrelated tools and actions. Enforce workflow transitions independently of instructions generated from artifact content.

  • M1047 Audit

    Require AI-assisted security analysis workflows to preserve analysis status, artifact provenance, tool execution, termination reason, and completion state so that incomplete or unexpectedly redirected analysis can be independently identified and reviewed.
